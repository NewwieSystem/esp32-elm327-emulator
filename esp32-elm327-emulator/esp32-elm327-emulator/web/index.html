👻 GHOSTCAR

Flash GhostCar to your ESP32

An ELM327 OBD-II emulator: ten virtual cars over Bluetooth Classic, BLE or Wi-Fi. Plug the board in with USB, pick it below and press Install.

cyd

Cheap Yellow Display

ESP32-2432S028R, 2.8" touchscreen. Try this one first.

cyd-invert

CYD, inverted panel

Same board, for panel batches that show negative colours with the normal build.

esp32dev

Any ESP32 board

WROOM-32 / WROVER without a screen. Control it from the serial console.

Needs Chrome or Edge on a computer (Web Serial). If the port does not show up, install the CH340 / CP210x USB driver for your board. ESP32-S3 / C3 boards are not supported yet.

After flashing

  1. Bluetooth Classic (default): pair with OBDII on Android or Windows, then pick it in your OBD app.
  2. iPhone: switch to BLE or Wi-Fi on the SETUP page (or type link ble in the serial console).
  3. Wi-Fi: join WiFi_OBDII, set the app to 192.168.0.10 port 35000.
